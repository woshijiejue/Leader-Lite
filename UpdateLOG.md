# Leader Lite B2.0 Update Log

## New Features
- Added HUD Designer with draggable layouts, snapping, color settings and module previews.
- Added Island with HUD fusion, animated states, target info, block counts and alerts.
- Added List-style ClickGUI.
- Added Potion Aura style, container filters for InventoryClicker and configurable Stuck timing.

## Improvements & Fixes
- Redesigned Island and HUD previews with a lighter UI.
- Fixed HUD scaling, click bounds, fusion handling and notification positioning.
- Fixed Island preview panel jumps and truncated ping units.
- Fixed FreeLook Hold/Toggle behavior, added automatic third-person view and perspective restoration.
- Updated Scaffold rotation and placement logic; removed the extra EarlyPlace path.
- Updated Velocity reduction options and removed the old Blink branch.
- Added List ClickGUI support to InvWalk.
- Improved key bindings, token login and HUD configuration saving.
- Updated AutoHypixel and cleaned up obsolete code.
